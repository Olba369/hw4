# Навчальний проект: CSS Селектори (hw4)

Цей проект створено як практичну роботу для засвоєння різних методів вибору елементів HTML за допомогою CSS.

## Опис проекту
Проект демонструє, як можна стилізувати елементи веб-сторінки, використовуючи різні типи селекторів: прості, контекстні, атрибутивні та селектори послідовності.

## Функціональні можливості
У проекті реалізовано стилізацію наступних елементів:
- **Базові селектори:** робота з тегами (`h1`) та класами (`.class`)[cite: 1].
- **Контекстні селектори:** застосування стилів до вкладених елементів (`div > p`, `div ul li`)[cite: 1].
- **Селектори атрибутів:** стилізація полів введення дати (`input[type="date"]`, `input[type*="local"]`)[cite: 1].
- **Селектори спорідненості:** використання тильди (`span ~ p`) для вибору елементів, що йдуть після вказаного[cite: 1].
- **Ідентифікатори:** використання `id` для унікальної стилізації окремих елементів (`#date`, `#checkbox`)[cite: 1].

## Особливості
- Проект наочно показує різницю між прямими нащадками та вкладеними елементами.
- Використано різні кольорові схеми для тестування видимості стилів у браузері[cite: 1, 2].
